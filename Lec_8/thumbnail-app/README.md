# 🎬 YouTube Thumbnail Generator

A **Next.js** project that generates **custom YouTube thumbnails** using **Gemini Nano Banana (Chat API)** for creative generation, **ImageKit** for file uploads, and **Lucide React** for sleek icons.  
The app also allows users to **download generated thumbnails** with a single click. 🚀  

---

## ✨ Features

- 🎨 Generate **AI-powered thumbnails** with Gemini Nano Banana (Chat API)
- ☁️ Upload and manage reference images with **ImageKit**
- ⬇️ **Download thumbnails** directly to your system
- ⚡ Built with **Next.js 14+** for performance and scalability
- 🖼️ Beautiful UI with **Lucide React icons** and **Tailwind CSS**
- 💻 Drag-and-drop file upload and multiple image support

---

## 🛠️ Tech Stack

- **Next.js** – React framework for frontend & API routes  
- **Gemini Nano Banana (Chat API)** – AI thumbnail generation  
- **ImageKit** – cloud image hosting and optimization  
- **Lucide React** – icon set for UI elements  
- **Tailwind CSS** – styling
